\section{Introduction}

A language agent can be warned, asked to replan, or rolled back when a trajectory appears to be failing. None of these repairs is free. A warning can displace useful context, a new plan can abandon partial progress, and a rollback can undo a correct action. A runtime controller must therefore answer a treatment-choice question: which action, including no intervention, has the highest expected utility from the current prefix?

The evaluation is easy to bias. Suppose an experiment restores one prefix, samples several intervention branches, and keeps the branch with the best observed outcome. Scoring that choice on the same branches measures a realized maximum and credits the selection rule for favorable continuation noise. The problem is acute in binary-success environments, where one lucky branch turns an otherwise tied menu into an apparent rescue, and repeating the task under a new seed does not help if the repeated outcome again both chooses and scores.

This distinction is separate from two established ideas: outcome regression and direct treatment-effect regression are alternative target parameterizations \citep{kunzel2019metalearners}, and separating selection from evaluation is a general remedy for maximization bias and adaptive reuse \citep{vanhasselt2010double,dwork2015generalization}. We apply both to intervention policies for language agents. The closest same-prefix study evaluates its main controller with one realized branch per action \citep{zhang2026calibration}.

We use two independently seeded continuations for each action from a shared prefix. Any policy fitted on separate development tasks is evaluated on both draws. For an outcome-informed oracle diagnostic, the action selected on one draw is evaluated on the other. This yields a symmetric, pathwise nonnegative gap between the observed maximum and the independent-draw value of the selected action. The gap measures how much a same-outcome analysis can overstate deployable utility on the sampled task frame. It does not establish that any learned intervention helps.

The same design answers a second question that a single draw cannot. Give an oracle one complete independent draw of every action and score it on another. The resulting value is what the strongest selection signal available at this draw count achieves per task. When it falls below the best arm in hindsight, the prefix-conditional signal at that decision point is weaker than the menu's average effect, and a controller that must recover that signal from features alone is in a worse position still. The binding constraint is then the design, not the learner. Our first confirmation, with four fixed messages at a hash-assigned early step, is exactly that case. Our second confirmation changes two design variables and leaves the estimand, the protocol, and the learner family intact: the decision is taken when the public prefix first shows an invalid action, an inadmissible action, or an unchanged observation, and the menu separates repair depth from repair content by adding a three-decision restoration and a relocation message.

A third use of the repeated branches is internal to the controller. A deployed rule also maximizes, over estimated benefits rather than over outcomes, so the score its margin test sees is itself a realized maximum. Fitting one signed-benefit forest per development draw, choosing the action on one and valuing it on the other, moves the selection-versus-evaluation split from the evaluator into the controller at no extra data cost.

The controller comparison holds the development records, prefix features, four whole-task folds, 200-tree capacity, margin grid, and action menu fixed. One forest predicts arm outcomes; a second predicts signed benefits relative to continuation,
\begin{equation}
\Delta_a(x)=\mathbb{E}[Y_a-Y_0\mid X=x],\qquad a\neq0.
\end{equation}
Both can choose \textsc{Continue}. The candidate set also contains the development-best fixed arm, the strongest runnable arm-outcome policy, a comparison-only learner, and a failure-risk detector. All predictions were committed before confirmation outcomes existed.

The first confirmation panel contains \AlfPlanned{} ALFWorld tasks balanced over six task types and grouped by \AlfGroups{} floorplans, whose goal directories are absent from the supplied exposure packet, plus \SwPlanned{} reserved ScienceWorld variations as a boundary. The second adds \EventPlanned{} further identity-disjoint ALFWorld tasks. We report every frozen policy, costs, early-terminal tasks, and the adverse historical evidence.

The paper makes three contributions. It gives a repeated-branch protocol and a simple diagnostic that prevents a realized action maximum from being reported as policy value, together with a reference distribution that says how much of the diagnostic is mechanical. It turns the same protocol into a design instrument that bounds what a decision point and a menu can reach before any controller is fitted. It provides a controlled target-parameterization comparison, extends it with cross-draw selection inside the controller, and releases a pre-outcome configuration, prediction freeze, bounded compute ledger, full result census, and scripts that regenerate every table and figure. The empirical conclusions are stated in Section~\ref{sec:results}; they are not widened beyond the frozen tests.

\section{Evaluating a runtime intervention}
\label{sec:estimand}

\subsection{Policy value after a shared prefix}

Let $X_i$ be the observable prefix for task $i$ at its assigned checkpoint and let $E_i=1$ when the episode ends before that checkpoint. The action set is $\mathcal{A}=\{0,\ldots,K\}$, where $0$ means continue without an injected message. A stochastic continuation under action $a$ produces binary task success $Y_{ia}\in\{0,1\}$ with conditional mean $\mu_a(x)=\mathbb{E}[Y_{ia}\mid X_i=x]$. A prefix-only policy $\pi(a\mid x)$ acts only on eligible prefixes, so the reported task-level value is a mixture,
\begin{equation}
V(\pi)=\mathbb{P}(E=1)\,\mathbb{E}\!\left[Y^{\mathrm{early}}\mid E=1\right]
+\mathbb{P}(E=0)\,\mathbb{E}_{X\mid E=0}\!\left[\sum_{a\in\mathcal{A}}\pi(a\mid X)\mu_a(X)\right].
\label{eq:policy-value}
\end{equation}
Early-terminal tasks contribute their observed terminal outcome to every policy, so they cancel from every contrast and enter only the denominator. The expectation includes continuation randomness. A single fresh draw per task is already an unbiased estimate of $V(\pi)$ for a policy committed before that draw; the bias studied next arises only when the action is chosen using the outcome that then scores it. A controller that always intervenes can have lower value than continuation even when it correctly detects a difficult prefix. Detection quality and treatment choice are different estimands \citep{vasudev2026failure}.

Our simulated environments permit a repeated-branch design. From the same serialized state, we generate two draws $Y_{ia}^{(0)}$ and $Y_{ia}^{(1)}$ for every action. The request seeds are independent deterministic hashes of task, draw, action, and request index. Full-state hashes validate restoration before the first suffix call. The actor sees only the common public prefix, the assigned message, and subsequent observations.

\subsection{The same-draw optimism diagnostic}

Define $\widehat a_i^{(r)}=\arg\max_a Y_{ia}^{(r)}$, resolving ties by the lowest action index, so continuation wins every tie it enters and the lowest-indexed successful intervention wins otherwise. A same-draw analysis scores this outcome-informed choice as $\max_aY_{ia}^{(r)}$. Cross-draw evaluation instead scores the selected action on the other draw. We use the symmetric gap
\begin{equation}
G_i=\frac{1}{2}\!\left[
\max_aY_{ia}^{(0)}-Y_{i,\widehat a_i^{(1)}}^{(0)}+
\max_aY_{ia}^{(1)}-Y_{i,\widehat a_i^{(0)}}^{(1)}
\right].
\label{eq:gap}
\end{equation}

\textbf{Proposition 1.} $G_i\geq0$ for every realized pair of action-outcome vectors. If the two action-outcome vectors are independent and identically distributed conditional on $X_i$, then $\mathbb{E}[G_i\mid X_i]$ equals the expected same-draw maximum minus the independent-draw value of the action chosen on that draw.

The pathwise statement follows because each maximum is at least the outcome of the action selected on the other draw; it needs no distributional assumption. Conditional independence is what factors the cross-draw term into the value of the selection rule on a fresh continuation, and identical distribution is what makes the two orderings interchangeable. Without independence the identity fails: two perfectly dependent draws give $G_i\equiv0$ while the expected same-draw maximum still exceeds the independent-draw value whenever continuation outcomes are stochastic. With $R>2$ draws the same statement holds for the average of $G$ over ordered draw pairs. A positive $G_i$ can arise from unstable binary outcomes even when all actions share a conditional mean. Because $G_i\geq0$ pathwise, a sign-flip null is degenerate for it: every group sum is non-negative, so the test can only reject the sharp null of deterministic continuations. We therefore treat $G$ as an estimation diagnostic and read it against a within-task reference that permutes the action and draw labels of the recorded outcomes, fixing the noise level and removing action structure. Appendix~\ref{app:proof} gives the derivation and tie cases.

Figure~\ref{fig:design} shows the information boundary. Frozen policies use the prefix only. The outcome-informed selector exists solely to quantify same-draw optimism; it is not a deployable method or a training label for the confirmation policies.

\section{Controllers with a continuation option}
\label{sec:controllers}

\subsection{Matched target parameterizations}

The repeated arm-outcome learner fits a multi-output random forest \citep{breiman2001random} to
\begin{equation}
\bar Y_{ia}=\frac{Y_{ia}^{(0)}+Y_{ia}^{(1)}}{2},\qquad a\in\mathcal A.
\end{equation}
At prediction time it compares the estimated outcome mean of every action. The direct learner uses the same records but fits three outputs,
\begin{equation}
\bar D_{ia}=\frac{1}{2}\sum_{r=0}^{1}\left(Y_{ia}^{(r)}-Y_{i0}^{(r)}\right)=\bar Y_{ia}-\bar Y_{i0},
\qquad a\neq0.
\end{equation}
Its continuation score is fixed at zero. Thus the two learners differ in the response target while retaining the same action menu and predictor class. The comparison does not assume that direct effect regression is uniformly preferable; such an ordering is absent even in standard heterogeneous-effect settings \citep{kunzel2019metalearners}.

Both learners receive public information available at the fork: environment identifier, checkpoint index, counts of invalid or inadmissible actions, reward and usage summaries, action repetition signals, recent observations and actions, and recent prefix text. Hidden state hashes and reversibility metadata are excluded. Numeric fields are vectorized directly. Recent text uses a 512-term TF--IDF vocabulary fitted within each training fold and at most 16 truncated-SVD components.

Model selection uses four shuffled folds that keep every record of a task together, with seed 260908. Each candidate has 200 trees, minimum leaf size 5 or 10, and a continuation margin in $\{0.00,0.05,0.10\}$. Vocabulary and projection fitting occur inside each fold. Out-of-fold utility selects the configuration, and lower intervention rate breaks utility ties. The final forests are refit on all admitted development tasks. Source and target hashes, fold identities, feature schemas, library versions, and every candidate score are stored in the model manifests.

\subsection{Cross-draw selection inside the controller}
\label{sec:crossdraw}

A deployed controller also maximizes. It compares estimates $\widehat\Delta_a(x)$ and fires the arm attaining their maximum, so the score that the margin test sees is a realized maximum over noisy estimates and inherits the bias of Section~\ref{sec:estimand} at the estimation level rather than the outcome level. The repeated-branch design already supplies the remedy it needs. We fit one signed-benefit forest per development draw, $\widehat\Delta^{(0)}$ and $\widehat\Delta^{(1)}$, on identical features, folds, and capacity. The arm is chosen on one draw and valued on the other,
\begin{equation}
\widehat a^{(r)}(x)=\arg\max_a\widehat\Delta^{(r)}_a(x),
\quad
V^{(r)}(x)=\widehat\Delta^{(1-r)}_{\widehat a^{(r)}(x)}(x),
\quad
S(x)=\begin{cases}\tfrac12\left[V^{(0)}(x)+V^{(1)}(x)\right] & \widehat a^{(0)}(x)=\widehat a^{(1)}(x),\\[2pt] \max_r V^{(r)}(x) & \text{otherwise,}\end{cases}
\label{eq:crossdraw}
\end{equation}
and the controller fires the arm attaining $S(x)$ when $S(x)$ exceeds the continuation margin. Two entries join the shared grid: whether to require $\widehat a^{(0)}(x)=\widehat a^{(1)}(x)$, which declines to act when the draws disagree about which repair the prefix calls for, and whether to restrict the candidates to the two arms with the highest mean benefit inside the training fold. Both are chosen by development out-of-fold utility before any confirmation outcome. Equation~\ref{eq:crossdraw} is Equation~\ref{eq:gap} moved from the evaluator to the controller: the same symmetric construction applied to estimates rather than outcomes, and the same requirement that the quantity used to choose never be the quantity used to value.

Model selection faces the same problem once more, because the grid is scored and then maximized on the same folds. We therefore also report a nested out-of-fold utility that selects inside each training fold and scores on the held-out fold.

\subsection{Fallbacks and the comparator}

\textsc{Continue} always chooses $a=0$ and \textsc{Best fixed} always chooses the development-best arm, which is replanning ($a=2$). \textsc{Direct} uses the signed-benefit learner and \textsc{Arm outcome} the two-draw outcome forest; this pair is the sample-matched target-parameterization contrast, because both fit the same two-draw rows. \textsc{Matched comparator} is instead the strongest runnable member of the existing arm-outcome family by development out-of-fold utility, which is \textsc{Single-1}, a forest fitted to one predesignated draw; comparing \textsc{Direct} against it therefore measures the target parameterization together with the draw count, and is reported as the strongest available benchmark rather than as the clean parameterization test. The second confirmation adds \textsc{Cross-draw} and two learners that instantiate the closest external objectives inside this interface: a comparison-only forest fitted to the sign of $Y_a-Y_0$, and a failure-risk detector that gates a fixed arm on predicted continuation failure.

The operational candidate set is $\{\textsc{Continue},\textsc{Best fixed},\textsc{Direct},\textsc{Matched comparator}\}$. Its development-only selection uses the same utility and tie rule. The selected policy is reported as \textsc{Safe selected} even when it is a baseline or an existing learner. In both environments the frozen selection chose \textsc{Single-1}. Calling this rule safe means only that it can decline intervention and was selected without confirmation outcomes; it is not a safety guarantee.

\section{Independent confirmation design}
\label{sec:design}

We design two frozen confirmations to answer four questions in the order the results report them: (1) how much does same-draw action selection overstate independent-draw value, and how much of that is continuation noise; (2) does a matched controller improve on continuation and on the best fixed repair at a scheduled checkpoint with four fixed messages; (3) what do the same branches say that decision point and that menu could have delivered; and (4) does moving the decision to the first public failure signal, separating repair depth from repair content, and decoupling the controller's own choice from its own valuation change the answer to (2).

\subsection{Actor and interventions}

The actor is Qwen3-8B at revision \texttt{b968826d9c46dd6066d109eabc6255188de91218} \citep{yang2025qwen3} under a grounded ReAct-style prompt \citep{yao2023react}: one short thought followed by an exact valid action, thinking mode disabled, temperature 0.7, top-$p$ 0.9, at most 256 output tokens, and a 32,768-token context. Serving uses deterministic-inference mode in a content-addressed SGLang container, which fixes the sampling implementation for the study without claiming invariance across serving systems \citep{bjarnason2026randomness}.

ALFWorld episodes have a 50-action limit and scheduled checkpoints at step 4 or 8 \citep{shridhar2021alfworld}. ScienceWorld episodes have a 100-action limit and checkpoints at step 8 or 16 \citep{wang2022scienceworld}. A hash of each task identity assigns the checkpoint before generation. Action 3 restores the state before the last executed action and reduces the suffix limit by one. The other arms restore the checkpoint state. This gives every arm the same total decision budget. The intervention message is inserted once at the restored step and remains in history; no controller sees future state or outcome fields.

The second confirmation keeps this actor, seeding, serving image, and restoration contract and changes only the decision rule and the menu. Its checkpoint is the first step between 2 and 24 at which the public prefix shows an invalid action, an inadmissible action, or an observation identical to the preceding one; a task with no such step has no intervention decision. Its menu keeps arms 0--3 verbatim and adds an arm that reverts the three most recent decisions before replanning and an arm that asks the actor to name the objects still required and the places not yet inspected. Reverting $k$ decisions reduces the suffix limit by $k$, so every arm still costs the same total number of decisions. Its \EventPlanned{} identities are run under both the scheduled and the event rule, which makes the rule contrast paired at the task level.

Each task first receives one baseline episode. A task that terminates before its checkpoint has no intervention decision; its terminal success is assigned to every policy and its contrasts are zero. For every eligible task the continuation arms are generated fresh rather than copied from the baseline suffix, because that trajectory helped define the prefix.

\subsection{Panels and exposure boundary}

The primary panel has \AlfPlanned{} ALFWorld tasks, 64 from each of the benchmark's six task types, drawn from the training source because it supplies enough identity-disjoint instances for a powered confirmation. Selection excluded 394 goal directories appearing in 59 supplied prior configurations or outcome records; the remainder were ranked by a fixed hash seed and form \AlfGroups{} floorplan groups. This is a fresh study panel relative to the supplied research archive, not a claim that the instances never appeared in pretraining. Development results favored ALFWorld, so the domain was fixed before sampling and before predictions were frozen. The secondary panel has \SwPlanned{} ScienceWorld official-test variations from a previously reserved frame, spanning \SwGroups{} task families; no ScienceWorld outcome changes the primary family or controller tuning. The second study draws \EventPlanned{} confirmation identities and a disjoint development panel from the same inventory after also removing every goal directory used by the first panel. Appendix~\ref{app:lineage} gives the construction and exclusions.

The panel configuration and hypotheses were committed before baseline generation. After all baselines, the feature transforms and one-hot policy choices for \EligibleTotal{} eligible prefixes were hashed and committed before any arm outcome. The freeze contains \AlfEligible{} ALFWorld and \SwEligible{} ScienceWorld predictions. Appendix~\ref{app:lineage} gives the commit and SHA-256 lineage.

\subsection{Hypotheses, uncertainty, and stopping}

The first confirmation's ALFWorld family contains mean same-draw optimism $\mathbb E[G]$, \textsc{Direct} minus \textsc{Continue}, and \textsc{Direct} minus \textsc{Matched comparator}; the second confirmation's family contains \textsc{Cross-draw} minus \textsc{Continue} and \textsc{Cross-draw} minus \textsc{Best fixed}, and reports $\mathbb E[G]$ as an estimate because a sign-flip null is degenerate for a pathwise nonnegative quantity. Each contrast is the paired task difference averaged over all planned tasks, with early-terminal tasks contributing zero. We use a two-sided sign-flip test over floorplan-group sums with 50,000 Monte Carlo assignments and apply Holm correction within each family at familywise $\alpha=0.05$. A positive estimate with an adjusted $p$ value above 0.05 is not called an improvement.

The freeze is what makes the variance reduction safe. Fitting the machinery that lowers variance on the data it will later evaluate is enough to produce any desired conclusion: in extensive-form game evaluation, a heuristic value function tuned on the evaluation sample can be driven to pathologically low variance or to a chosen test statistic, so the function must be fixed before that sample is seen \citep{kim2026aivat}. Our controllers, transforms, and decision rules are hashed and committed before any confirmation outcome exists for the same reason. Panel size follows from the development operating point rather than from convenience. Treating each task as a paired binary comparison \citep{miller2024errorbars}, the development contrast against continuation needs roughly a thousand analysable tasks for conventional power, while the contrast against the best fixed repair needs an order of magnitude more; the second is therefore reported as an estimate and is not tested. Repeated continuations are the variance reduction that makes the first contrast measurable at all, which is the same device \citet{miller2024errorbars} recommends for single-turn evaluations. Intervals are 10,000-resample percentiles at two levels: a task bootstrap and a grouped bootstrap over complete floorplans or ScienceWorld families. They are descriptive; the sign-flip and Holm procedure is the decision rule. The evaluator also reports every remaining contrast, intervention rate, action counts, recoveries, disruptions, and costs, and every ScienceWorld comparison is retained regardless of sign. No task is removed for a poor outcome, and missing eligible cells block final analysis. Appendix~\ref{app:statistics} gives the complete specification and Appendix~\ref{app:lineage} the administrative resumes.

\section{Closest methods and comparison boundary}

\textbf{Same-prefix intervention learning.} Calibration Is Not Control fits random-forest intervention policies from same-prefix branches, but evaluates its main controller with one realized outcome per action \citep{zhang2026calibration}. COTA trains a 0.5B pairwise advisor and reports 82.84--90.30\% ALFWorld success with Qwen3-8B \citep{jiang2026cota}; its labels come from the same construction as ours, so the diagnostic of Section~\ref{sec:estimand} applies to its supervision as well as to our evaluation, while its 30-step actor, environment-action candidates, repeated schedule, and offline budget differ from our one-shot menu, so its headline score is not a matched estimate of our contrast. Compared with both, this study values the option of not intervening on continuations that did not choose it. \textbf{Critic-based runtime supervision.} Asymmetric actor-critic supervision pairs a large actor with a small intervening critic \citep{jiang2026asymac}, and AgentTether localizes a failure-critical subtrajectory and re-executes with scoped guidance \citep{zhao2026agenttether}. Both choose what to say; neither estimates the utility of declining to intervene. Within our frozen interface we therefore run the comparison-only learner that COTA's objective implies and the failure-risk detector of \citet{vasudev2026failure}, matched on features, folds, capacity, actor revision, and decision budget.

\textbf{Protecting a selected claim.} The same discipline has been applied one level up. Selection-aware stress testing freezes a task reweighting chosen on discovery tasks and re-evaluates it on separate confirmation tasks, reporting no claim when support fails; on $\tau$-bench with a Qwen3-8B actor a 3.75-point discovery gain vanished on confirmation \citep{xu2026sasst}. Compared with that protection, ours acts one level down: the unit of reuse is the continuation that scores an action rather than the task mixture that weights a benchmark, and the two compose.

\textbf{Search-based repair.} This is a different cost class. Language agent tree search expands and scores many continuations per decision and commits to the best \citep{zhou2024lats}. That procedure is the deployable form of the outcome-informed selector in Equation~\ref{eq:gap}, and Proposition 1 says exactly what it costs to score such a procedure on the branches that chose it. Our menu spends one suffix per task, so we report the selector as a diagnostic rather than as a baseline we outrank.

\textbf{Estimation.} Outcome modeling estimates every response function; direct signed-benefit modeling estimates effects relative to continuation \citep{kunzel2019metalearners}. Cross-draw scoring separates maximization from evaluation, following the principle behind Double Q-learning \citep{vanhasselt2010double}, and Section~\ref{sec:crossdraw} carries it into the controller. Inference-aware policy optimization characterizes the frontier between a learned policy's expected gain and the significance of that gain \citep{bastani2025inference}; Section~\ref{sec:analysis} reads our margin grid against that frontier and finds the frozen point at its most significant end. Every action here is executed from a serialized simulator state, so the estimand is the utility of the frozen menu, not a general causal effect or a benchmark rank. Our environments randomize only token sampling; Section~\ref{sec:analysis} shows the diagnostic is a function of per-task outcome variance, so a domain whose tools and simulated users add randomness, as in $\tau$-bench \citep{yao2024taubench}, moves it upward.

\section{Limitations, ethics, and conclusion}

\paragraph{Limitations.} The confirmations cover one 8B actor, two text environments, six fixed repairs, one trigger rule, and two draws per action, and not web or code agents. The triggered gain over continuation is positive but not certified: the pre-registered calculation put the required panel near 1,100 identity-disjoint tasks and the balanced pool was exhausted at \EventPlanned{}. The first confirmation's null is bounded to a coarse menu at an early step, where headroom and capacity both locate the ceiling. ScienceWorld is boundary evidence, reported in full and pooled with nothing.

The study uses simulated household and elementary-science tasks and contains no human-subject data. Interventions can still degrade task success, so the artifact reports disruptions and includes continuation as an action. Compute is capped and charged by GPU occupancy. The supplementary archive removes user names, host names, repository ownership, and absolute paths.
