Selecting a runtime intervention and evaluating it on the same stochastic continuation credits favorable branch noise. We test this problem with four actions, including no intervention, and two independent continuations from each shared prefix. The confirmation covers 384 identity-disjoint ALFWorld tasks (96 floorplan groups), with predictions frozen before arm outcomes. The same-draw maximum overstates cross-draw value: the planned-task gap is 15.36 percentage points (group-bootstrap 95\% interval [12.46, 18.30], Holm-adjusted $p<10^{-4}$). Holding features, whole-task folds, forest capacity, and action support fixed, direct signed-benefit prediction changes success by 1.56 points versus continuation and $-$0.39 points versus the strongest runnable matched controller. Neither controller contrast reaches significance before or after multiplicity correction. We retain the complete ScienceWorld boundary panel and adverse historical results, and make no cross-harness state-of-the-art claim. The resulting protocol turns an outcome-selected rescue into an auditable policy-value estimate.
