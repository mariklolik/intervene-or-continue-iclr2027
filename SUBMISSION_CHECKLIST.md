# ICLR 2027 submission checklist

Checked against the official ICLR 2027 author guidelines and AI policy on 2026-09-14.

## Automated gates

- [x] Main text ends within page 9 in `paper/main.pdf`; references and appendix follow it.
- [x] Official `iclr2027_conference.sty` is used without margin, font, spacing, or heading overrides.
- [x] Submission mode is anonymous and contains no acknowledgments, repository owner, user name, host name, absolute path, or identifying metadata.
- [x] Every citation key resolves to a verified primary source.
- [x] Every quantitative statement resolves to a frozen artifact or explicitly labeled exploratory result.
- [x] The full denominator, adverse ScienceWorld results, missingness, compute, and multiplicity correction are reported.
- [x] The reproducibility statement points to the appendix and anonymous supplementary archive.
- [x] The manuscript contains the required AI-use statement.
- [x] The supplement archive reproduces every table and figure without network access except for model and benchmark acquisition described in the appendix.
- [x] The supplement SHA-256, source commit, prediction-freeze commit, panel hash, and result hash agree with the supplement-internal `artifacts/MANIFEST.json`.
- [x] PDF fonts, links, figures, tables, and all rendered pages pass visual inspection.

## Author actions

- [ ] Submit the abstract by 2026-09-18 23:59 AoE and the paper by 2026-09-25 23:59 AoE.
- [ ] Enter the complete and final author list before the abstract deadline; do not add authors afterward.
- [ ] Enter affiliations, conflicts, profile information, and reviewer obligations truthfully in OpenReview.
- [ ] Review the manuscript AI-use disclosure and select the matching task categories in the submission form.
- [ ] Check every author and affiliation against the current official OFAC sanctions lists and obtain institutional or legal guidance if any possible match exists. Do not omit, alter, or disguise an affiliation to change eligibility.
- [ ] Review the anonymous supplementary archive before upload and retain the private repository until double-blind review permits de-anonymization.
